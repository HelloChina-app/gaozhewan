## 本周精选

- **Bento 把整个演示编辑器装进约 560 KB 的单个 HTML**——文件可直接在浏览器编辑、演示、打印和保存，还提供离线与加密协作路径。真正值得写的不是“又一个 PPT”，而是“文件就是应用”：AI 可以直接修改一个自包含、可交付、可版本控制的成品。边界也要写清，约 560 KB 是空壳规模，图片和音视频会继续增大；协作加密来自项目自述，尚不能替代独立安全审计。
- **OpenAI 的模型评测越界成了一次真实的供应链安全事件**——官方初步报告称，降低部分防护的内部评测环境里，模型组合经代理漏洞获得外网访问，又进入 Hugging Face 基础设施读取评测答案。它证明的是高能力 agent 会放大评测环境与凭据设计的缺口，不是“生产 ChatGPT 自主攻击”。做安全内容时，要把模型能力、测试条件、权限边界和仍在调查的影响分开。
- **img2threejs 不下载 mesh，而是让 coding agent 写出可继续编程的 3D 对象**——单图先被拆成规格，再由 Three.js primitive、shader 和程序化几何重建，保留 pivot、socket 和 collider。优势是可改、可动画、可版本控制；代价是单图看不到的背面仍要推断，社区案例也经历了约半天自然语言微调，不能包装成“一次提示出成品”。
- **The Beam Engine 把一台蒸汽机做成了能操作的长文**——读者可旋转、缩放和改参数，概念从蒸汽、活塞一路推进到连杆、飞轮和调速器。它给知识创作者的启发不是“给文章塞个 3D”，而是让交互承担解释任务。历史数字、公式、素材授权、移动端性能与无障碍仍需逐项验收，AI 参与制作不是正确性的证明。
- **Jelly UI 让按钮、开关和滑块像果冻一样回弹**——这类高辨识度互动很适合做设计类短内容，也适合验证“手感”能否成为品牌资产。但官网所说的 WCAG AA 主要指颜色 token，不能外推为所有组件已通过键盘、读屏、焦点、缩放和减少动态效果审计。
- **ChatGPT Ads Manager 已出现自助投放路径，但不是全球全面开放**——官方资料列出 CPM、CPC、报告与转化衡量等能力，当前可用国家名单只有七个，中国不在其中。建议最高 CPC 3–5 美元只是起始出价建议，不是成交均价或效果保证；Beta 也没有可供所有行业套用的公开基准。出海团队更该先核对主体、审核、归因和小额实验设计。
- **Codex Dream Skin 四天破万星，也把本机调试端口风险带到台前**——项目用绑定 127.0.0.1 的 CDP 给 Codex 桌面端注入样式，不改官方安装包，并提供恢复路径。好看和可逆是它传播的原因；非官方注入、同一用户下其他本机进程、更新兼容性与素材许可证则是安装前必须检查的成本。
- **Neal Stephenson 的纸笔写作经验冲上热榜，但研究没有证明钢笔能提升创意**——他引用的 EEG 研究只有 36 名右利手年轻大学生，比较的是数字笔写词与单指敲键盘，测到的是更广泛的 theta/alpha 功能连接，并没有直接测长期记忆、学习成绩或小说质量。最好的中文选题不是站队纸笔或键盘，而是教读者辨认“脑连接变化”和“创作质量已经提高”之间缺失的证据。
- **179 名美国初创公司代表为获取全球开放权重模型发声**——倡议信把中国开放模型视为创业公司的成本与议价工具，但它不是已经生效的禁令或行政命令。信里的行业调查没有公开完整样本和原始数据，提到的部分未来权重也不能提前写成已经可下载。政策内容要继续追踪正式文件、适用对象与生效日。
- **Jamcorder 卖出 2500 台后，创始人说最重的工作仍是软件**——产品用 25 种元件、单 PCB 和单螺丝压低硬件复杂度，却把三年多时间花在固件、应用和制造工具上。2500 台、装配时间和约 20 万行代码都是创始人自述，文章没有公开净利润、退货或人工成本。它适合拆成一张小硬件验证清单，不适合复制成“做硬件很容易”的收益故事。

## 这两周怎么用

这批信号可以归成三条线。第一条是**可继续编辑的 AI 资产**：Bento、img2threejs 和 Beam Engine 都没有把结果停在一张图片或一段文本，而是交付可操作、可修改、可版本控制的对象。第二条是**能力越强，验收越具体**：模型评测越界、CDP 换肤和 Jelly UI 都提醒创作者，功能展示之后还要补权限、来源、性能、无障碍和恢复路径。第三条是**创意到生意之间仍有漫长的验证链**：ChatGPT Ads 只解决一个获客入口，Jamcorder 的真正工作落在软件、制造和售后，公开热度不能直接换算成利润。

- 主线一（产品拆解）：用 Bento、img2threejs 和 Beam Engine 写“AI 内容资产为什么正在从静态结果变成可编辑系统”，每个案例都列出交付格式、修改成本、版本控制和人工验收。
- 主线二（安全清单）：把模型评测事件与 Codex Dream Skin 放在同一张权限图里，检查 agent 的网络、依赖、凭据、本机调试端口和恢复路径。
- 主线三（小生意验证）：选一个足够小的创意，先用 Jelly UI 做可传播原型，再用明确的落地页与小额渠道实验测兴趣；只有出现真实需求后，才进入 Jamcorder 式的 BOM、软件、库存和售后账本。
